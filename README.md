# Welcome to Expo App 👋

This is an Expo project created with React Native.

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

## Features

- Login
- Register
- Home
- Profile
- Navigation
